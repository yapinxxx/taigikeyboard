# Obsidian development report exports

These 23 reports preserve the TaigiKeyboard development experience recorded in
the Obsidian issue archive. The original notes were read alongside the original
October 8, October 9, October 21–23, October 31–November 1, and November 5–6
development sessions. Language versions already present in the source are kept.

These are historical records, not instructions for the current build. They
include superseded Space behavior, six-key pages, old per-user installers, and
older source hashes. The current workflow uses eight sentence keys and the
newer integration described in [current progress](../../PROGRESS.md).

Private machine paths were removed or replaced with source-relative artifact
descriptions. Local binaries, learning databases, raw session transcripts,
keyboard backups, and diagnostic logs were not copied into this public archive.
Those references identify historical evidence; their presence in a report does
not mean that the artifacts are available in this repository.

[source-manifest.json](source-manifest.json) records each original note's SHA-256
and the exported file's SHA-256. It allows later comparisons with the vault
without exposing the vault's absolute path or internal session identifiers.

The eight bilingual author-feedback drafts and their existing replay captures
are already in [author feedback](../../author-feedback/2026-10-23/README_en-US.md).
They are not duplicated here.
